# Isabella — anime demo

API kalitisiz ishlaydigan Isabella ko‘rinish va ovoz namoyishi. 


Bu faqat ko‘rgazmali versiya. Haqiqiy AI muloqot uchun backend va serverdagi API kalitlari kerak. API kalitini GitHub’ga joylanmagan. Ovoz brauzer tizimidagi mavjud sintez ovozidan foydalanadi; o‘zbekcha ovoz bo‘lmasa talaffuz tabiiy bo‘lmasligi mumkin.
