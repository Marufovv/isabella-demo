# Isabella — anime demo

API kalitisiz ishlaydigan Isabella ko‘rinish va ovoz namoyishi. `index.html` faylini brauzerda oching.

## GitHub Pages orqali chiqarish

1. GitHub’da yangi **public** repository yarating (masalan, `isabella-demo`).
2. Shu papkadagi `index.html` va `README.md` fayllarini repository bosh papkasiga yuklang va commit qiling.
3. Repository **Settings → Pages → Build and deployment → Deploy from a branch** ni tanlang.
4. `main` branch va `/ (root)` papkasini tanlab **Save** bosing.
5. Sayt manzili `https://USERNAME.github.io/isabella-demo/` bo‘ladi. Bir necha daqiqa kutib sahifani yangilang.

Bu faqat ko‘rgazmali versiya. Haqiqiy AI muloqot uchun backend va serverdagi API kalitlari kerak. API kalitini GitHub’ga joylamang. Ovoz brauzer tizimidagi mavjud sintez ovozidan foydalanadi; o‘zbekcha ovoz bo‘lmasa talaffuz tabiiy bo‘lmasligi mumkin.
